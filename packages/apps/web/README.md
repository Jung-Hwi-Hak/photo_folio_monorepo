# Chartjs 포토폴리오

React 기반 웹 애플리케이션입니다.
이 프로젝트는
[Next.js](https://nextjs.org/)와
[TypeScript](https://www.typescriptlang.org/)를 사용하여 개발되었습니다.

## 🛠️ 기술 스택
* React 19
* Next.js 16
* TypeScript 5
* Yarn Workspaces (Monorepo 구조)
* framer-motion 12.23.25
* lodash 4.17.21

## 🚀 시작하기

### 1. 저장소 클론
```bash
git clone https://github.com/username/project-name.git
cd project-name
```
### 2. 의존성 설치
```bash
yarn install
```
### 3. 개발 서버 실행
```bash
yarn workspace web dev
```

## 📦 빌드

```bash
yarn workspace web build
yarn workspace web start
```
